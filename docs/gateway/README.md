## Usage Rules

1. Before **adding or modifying any RPC call**, verify the method name and parameter fields in the corresponding module doc;
2. Method names must exist in the contract and parameter keys must fall inside the allowlist, otherwise `npm run contract:verify` fails;
3. New call sites must include probe evidence so `npm run contract:coverage` confirms every method is backed by real response fixtures or an explicit skip reason;
4. After upgrading the gateway, run `npm run contract:sync` followed by `npm run probe:gateway`;
5. Every file in this directory is generated; CI checks that re-running `contract:doc` produces zero diff.
